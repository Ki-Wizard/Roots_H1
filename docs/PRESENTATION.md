# PhiloType 중간 발표 흐름

## 1. 문제 정의

기존 성격 검사는 “당신은 어떤 유형이다”라는 결과에 집중합니다. 하지만 같은 선택을
하더라도 사람마다 이유는 다릅니다. PhiloType은 선택 결과보다 선택의 기준을
보여줍니다.

## 2. 한 줄 소개

딜레마 선택과 답변 이유를 바탕으로 사용자의 철학적 사고방식과 가치 판단 기준을
분석하는 서비스입니다.

## 3. 핵심 차별점

- 5단계 선택값과 한 줄 이유를 함께 분석
- 단순 철학자 매칭이 아닌 4개 사고축 프로필 제공
- 결과에 실제 답변 근거를 표시
- 나와 반대되는 관점과 사고 훈련 처방전 제공
- 공유 가능한 결과 카드

## 4. 사용자 흐름

1. 사용자가 딜레마 질문에 답합니다.
2. 각 선택의 이유를 한 문장으로 작성합니다.
3. 코드가 사고축 점수를 계산합니다.
4. 대표·보조 철학 유형과 철학자를 매칭합니다.
5. 리포트 생성기가 선택 이유를 설명과 근거로 변환합니다.
6. 결과 카드, 반대 관점, 사고 훈련, 공유 문구를 보여줍니다.

## 5. 기술적 판단

AI가 점수와 유형까지 결정하면 같은 답변에도 결과가 흔들릴 수 있습니다. 그래서
분류는 코드가 담당하고 AI는 해석 문장만 담당하도록 역할을 나눴습니다.

현재는 운영진이 안내한 Claude/OpenRouter 제한이 확정되지 않아 외부 AI를 호출하지
않습니다. 동일 응답 스키마의 Mock 구현으로 전체 흐름과 API 계약을 먼저 검증했습니다.

## 6. 현재 진행 결과

### 백엔드

- 질문 3개 실제 동작, 전체 8개 설정 데이터 설계
- 4개 사고축 가중치·정규화 계산
- 대표·보조 철학 유형 및 철학자 매칭
- 입력 누락·범위 검증
- Mock 리포트와 동일 입력 결정성 테스트

### 프론트엔드

- 시작, 설문, 로딩, 결과 화면
- 모바일 반응형 UI
- 5단계 응답과 한 줄 이유 입력
- 사고축 그래프, 답변 근거, 처방전, 공유 문구

## 7. 시연 순서

1. `GET /api/health`에서 `aiMode: mock`, `persistence: false`를 확인합니다.
2. 웹에서 딜레마 질문 3개에 답하고 이유를 작성합니다.
3. 분석 결과의 대표 유형과 4개 사고축을 확인합니다.
4. 답변에서 생성된 근거와 사고 훈련 처방전을 보여줍니다.
5. 같은 응답에는 같은 결과가 나온다는 테스트를 설명합니다.

## 8. 다음 단계

- 철학·기획 검토를 거쳐 질문 8개와 가중치 보정
- 운영진 확인 후 승인된 AI 제공자 연동
- Mock과 실제 AI 결과의 구조·안전 표현 검증
- 결과 공유 이미지와 친구 비교 기능 검토
