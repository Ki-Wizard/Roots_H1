# PhiloType 중간 발표 흐름

## 1. 문제 정의

기존 성격 검사는 “당신은 어떤 유형이다”라는 결과에 집중합니다. 하지만 같은 선택이라도 사람마다 이유는 다릅니다. PhiloType은 선택 결과보다 선택 기준을 보여주도록 설계된 서비스입니다.

## 2. 한 줄 소개

딜레마 선택과 답변 이유를 바탕으로 사용자의 철학적 사고방식과 가치 판단 기준을 분석하는 웹 서비스입니다.

## 3. 현재 구현된 기능

- 40개의 활성 딜레마 질문 제공
- A/B 선택과 한 줄 이유 입력
- 4개 사고축 점수 계산
- 대표·보조 철학 유형 및 대표 철학자 매칭
- 결과 카드, 반대 관점, 사고 훈련, 공유 문구 제공
- Mock 모드 기본 제공, OpenRouter 기반 실제 AI 리포트 생성 옵션 제공

## 4. 사용자 흐름

1. 사용자가 딜레마 질문에 답합니다.
2. 각 선택에 대한 이유를 작성합니다.
3. 서버가 사고축 점수를 계산합니다.
4. 대표 유형과 함께 결과 리포트를 확인합니다.
5. 결과 화면에서 근거, 반대 관점, 처방전, 공유 문구를 확인합니다.

## 5. 기술적 포인트

점수 계산과 유형 매칭은 서버 코드에서 결정합니다. AI는 해석 문장만 보완하므로, 같은 답변에도 결과가 흔들리지 않도록 역할을 분리했습니다.

기본 실행은 Mock 모드이며, 로컬 `.env`에서 `AI_MODE=openrouter`와 `OPENROUTER_API_KEY`를 설정하면 실제 AI 리포트 문장을 생성할 수 있습니다. Mock과 OpenRouter는 같은 응답 구조를 사용하므로 프론트엔드는 동일한 결과 화면을 렌더링합니다.

## 6. 현재 진행 결과

### 백엔드

- 40개 질문 데이터와 가중치 기반 점수 계산 구현
- 4개 사고축 정규화 및 유형 매칭 구현
- 요청 검증과 에러 응답 처리 구현
- Mock 리포트 생성기와 OpenRouter 리포트 생성기 구현
- AI 응답을 `GeneratedReport` 구조로 파싱하는 로직 구현

### 프론트엔드

- 시작, 설문, 로딩, 결과 화면 구현
- 모바일 반응형 UI 제공
- A/B 선택과 이유 입력 지원
- 사고축 그래프, 답변 근거, 처방전, 공유 문구 표시

## 7. 시연 순서

1. `GET /api/health`에서 현재 모드가 `mock` 또는 `openrouter`인지 확인합니다.
2. 웹에서 40개 질문에 답하고 이유를 작성합니다.
3. 결과 화면에서 점수와 유형을 확인합니다.
4. 생성된 근거, 반대 관점, 사고 훈련 처방전을 확인합니다.
5. 점수와 유형은 코드가 계산하고 AI는 문장 생성만 담당한다는 점을 설명합니다.
